# Changelog

## 0.4.1-alpha.1

First public alpha candidate, focused on old/new Godot add-on ZIP inspection.

- Shared CLI/Tk file-byte comparison, scan-time hashes, bounded text preview.
- Explicit unknown coverage, conservative missing-file handling and path-collision refusal.
- Source hidden by default in exported reports; source/destination protection.
- Installable wheel, English CLI/HTML, optional CI failure on byte changes.
- CI exit codes 0/1/2/3, including incomplete-scope priority.
- Original synthetic example, actual CLI transcript and typeset SVG demonstration.

Known limits: no adoption study, no semantic/native-code analysis, Chinese optional GUI, unclosed hostile directory races, no malware/safety certification. See README and validation before relying on results.
