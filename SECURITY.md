# Security and scope

This is a finite static review aid, not a malware detector, sandbox or safety certification.
Please do not upload credentials, private code, or malicious executables to public issues.
For a reproducible scanner defect, use a minimal synthetic, non-sensitive fixture and explain expected behavior.
If a release causes misleading results or unexpected reads/writes, stop relying on that version and report it.
Alpha releases can be marked obsolete and their download assets removed; reports include scanner/rule versions.
